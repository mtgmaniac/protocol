# Devlog: Sept 20 Update

### Help and onboarding

- Help now opens on Basics with turn flow, unit-card reading, Protocol, evolution and rewards, win/loss rules, and Replay Tutorial in one page.
- Keywords and action/effect icons are grouped into a single combat reference linked from Basics.
- Tutorial instructions stay within the visible desktop play area and offer assistance when a required action cannot be completed.
- The web build now fills whatever play area the browser or itch.io embed provides, spreading into extra width instead of forcing a narrow phone column.

### UI

- Strike, Splice, and Engineer use consistent battle portrait framing; Engineer is also corrected in the Squad Selector.
- Scrap and Rust sit correctly inside their existing portrait frames without clipped helmets.
- Unit reference rows have larger ability text, consistent portrait boxes, clearer hierarchy lines, and aligned HP values.
- Help has clearer hover feedback, a more visible scrollbar, reliable mouse-wheel scrolling, and consistent Escape behavior.
- Desktop builds use a small cyan sci-fi cursor with matching default and interactive states.
- Squad Select no longer cuts off the end of an operation's description on phone-width screens.

### Other

- The opening tutorial explains the core run and dice loop before introducing the board.
- Tutorial long-press and recovery behavior is more reliable at desktop scaling and high-DPI settings.
